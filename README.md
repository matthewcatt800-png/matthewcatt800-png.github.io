# Matthew's Digital Workshop

Personal portfolio and browser-based developer toolbox.

**Live site:** https://matthewcatt800-png.github.io/

## Overview
A responsive, terminal-inspired website built with vanilla HTML, CSS and JavaScript. It brings together project highlights and small utilities in one place.

## Toolbox
The site includes browser-based utilities for:
- Text transformations and text statistics
- JSON formatting and minification
- Base64 encoding and decoding
- URL encoding and decoding
- HTML entity escaping and decoding
- HEX and RGB colour conversion

## Privacy
Tool inputs are processed in the browser. The utilities do not need to upload the text being processed to a server.

## Running locally
Open `index.html` in a modern browser, or serve the repository with any simple static-file web server.

## Deployment
The site is published with GitHub Pages from the `main` branch.
