# Matthew's website

A responsive personal website and collection of browser-based utilities, published with GitHub Pages.

## What's inside
- Personal landing page and selected projects
- Text toolbox: character, word and line counts; case conversion; trimming
- JSON formatter and minifier
- Base64 encoder and decoder
- URL component encoder and decoder
- HTML escaping and unescaping
- Colour picker with HEX and RGB values

## Run locally
Open `index.html` in a modern browser. No build step or dependencies are required.

## Privacy
All utilities run client-side. Text entered into the tools is processed in the browser and is not uploaded to a server.

## Publish
GitHub Pages is configured to deploy from the `main` branch, root folder.
